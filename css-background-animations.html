CSS background animations

The code for all 5 ambient, explained

Every effect above, with the markup to use and the complete CSS. Each one is self-contained: paste the CSS once, add the class, done.

Float

A slow, weightless bob for hero illustrations and decorative elements. Vary duration per element so groups don’t sync up.

Markup

<img class="fh-float" src="illustration.svg" alt="" />

CSS

.fh-float {
  animation: fh-floatY 3.2s ease-in-out infinite;
}
@keyframes fh-floatY {
  0%, 100% { transform: translateY(0); }
  50%      { transform: translateY(-12px); }
}

Gradient Pan

A living background for hero sections. Animating background-position over an oversized gradient is far cheaper than animating the colours themselves.

Markup

<section class="hero fh-gradient-pan">…</section>

CSS

.fh-gradient-pan {
  background: linear-gradient(135deg,
    #8b5cf6, #06b6d4, #10b981, #8b5cf6);
  background-size: 300% 300%;
  animation: fh-gradientPan 6s ease-in-out infinite;
}
@keyframes fh-gradientPan {
  0%, 100% { background-position: 0% 50%; }
  50%      { background-position: 100% 50%; }
}

Aurora Blob

Morphing the two-value border-radius syntax creates organic, lava-lamp shapes. Add filter: blur(40px) for a soft background glow.

Markup

<div class="fh-aurora"></div>

CSS

.fh-aurora {
  width: 90px;
  height: 90px;
  background: linear-gradient(135deg, #8b5cf6, #06b6d4);
  animation: fh-auroraMorph 7s ease-in-out infinite;
}
@keyframes fh-auroraMorph {
  0%, 100% { border-radius: 60% 40% 30% 70% / 60% 30% 70% 40%; }
  25%      { border-radius: 30% 60% 70% 40% / 50% 60% 30% 60%; }
  50%      { border-radius: 50% 60% 30% 60% / 30% 60% 70% 40%; }
  75%      { border-radius: 60% 40% 60% 30% / 70% 30% 50% 60%; }
}

Pulse Ring

A radar ping radiating outward — the standard “live” indicator. The z-index: 0 on the parent keeps the ring behind the content but above the page.

Markup

<div class="avatar fh-pulse-ring"></div>

CSS

.fh-pulse-ring {
  position: relative;
  z-index: 0;
  width: 56px;
  height: 56px;
  border-radius: 50%;
  background: linear-gradient(135deg, #8b5cf6, #06b6d4);
}
.fh-pulse-ring::before {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: 50%;
  background: inherit;
  z-index: -1;
  animation: fh-ping 1.6s cubic-bezier(0, 0, 0.2, 1) infinite;
}
@keyframes fh-ping {
  from { transform: scale(1);   opacity: 0.7; }
  to   { transform: scale(1.9); opacity: 0; }
}

Slow Spin

A patient rotation for decorative badges, seals and background shapes. Linear easing keeps it hypnotic rather than mechanical.

Markup

<img class="fh-spin-slow" src="badge.svg" alt="" />

CSS

.fh-spin-slow {
  animation: fh-spinSlow 6s linear infinite;
}
@keyframes fh-spinSlow {
  to { transform: rotate(360deg); }
}

Ambient motion works by not being noticed

Everything in this category is designed to be felt rather than watched. A hero section with a slowly panning gradient feels alive; the same section with a fast, obvious animation feels distracting. The tuning rule is simple: if a visitor's eye is drawn to your background animation, it's too fast or too high-contrast.

Long durations are the key. Six to fifteen seconds per cycle is normal here, compared with the 150–600ms of interface feedback. Vary durations slightly between elements too — identical timings cause everything to sync up into an obvious pulse, while slightly different ones produce organic, non-repeating motion.

How the effects are built

The gradient pan animates background-position across a background sized at 300%, which is compositor-friendly — animating the gradient's colour definition would force a repaint every frame.

The aurora blob morphs the two-value border-radius syntax between several states, producing organic lava-lamp shapes no fixed shape could achieve. Add a large filter: blur() and it becomes the soft coloured glow used behind hero content on this site.

The pulse ring expands a pseudo-element outward while fading it — the standard radar-ping used for live indicators and active avatars.

Performance on real devices

Ambient animations run continuously, so they're the ones most likely to affect battery life and thermals on phones and laptops. Two practical limits: keep the number of simultaneously animating elements small — three or four is plenty — and be careful with large blurred elements, since blur is one of the more expensive filters, especially at full-viewport size.

Because these loop indefinitely, honouring prefers-reduced-motion matters more here than anywhere else. Continuous background motion is a common trigger for people with vestibular sensitivity, and a static gradient is a perfectly good fallback.

Keeping content readable

Animated backgrounds change the contrast behind your text as they move. Check the text against the lightest and darkest states the background passes through — not just the frame you happen to be looking at — using our contrast checker. If either extreme fails, add a semi-transparent scrim between the animation and the text.

Frequently asked questions

How slow should a background animation be?

Between six and fifteen seconds per cycle. Ambient motion should be felt rather than watched — if your eye is drawn to the background rather than the content, it is too fast or too high-contrast.

Do animated backgrounds hurt performance?

They can, because they run continuously and affect battery life. Keep the number of simultaneously animating elements to three or four, animate background-position rather than colour values, and be careful with large blurred elements.

How do I keep text readable over an animated background?

Check the text contrast against the lightest and darkest states the background passes through, not just one frame. If either extreme fails, add a semi-transparent scrim between the background and the text.
